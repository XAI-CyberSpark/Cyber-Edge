# Business-semantic node instances over generic capability nodes

The canvas should show product managers business-semantic node titles such as "识别儿童危险动作" or "抽取联系人和消息内容", while each visible node is backed by a reusable capability node type such as intent recognition, perception, slot extraction, risk evaluation, HMI output, app action, fallback handling, or acceptance checking. This keeps scenario authoring understandable to product managers without turning every scenario into a hard-coded template.
