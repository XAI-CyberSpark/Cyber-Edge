# HMI 作为体验仿真的主界面

日期：2026-09-11。状态：用户确认。

## 决策

智能座舱仿真以 HMI 作为体验呈现入口：中央车辆模型、车辆控制、助手反馈。空间和道路画面不再是默认的主界面。测试工具可收起，按场景注入状态和故障。

HMI 不是仿真执行器。车窗由独立 VehicleWorld 维护实际状态，手动控件和 GraphEngine 调用同一执行器，完成后返回实际结果。车模和控制面板订阅这份状态。

先实现下雨关窗及卡窗反馈的行为闭环，不引入外部地图、物理仿真服务或真实车辆连接。静态车模的侧窗按几何区域分离，用于开度视觉反馈，不宣称经过车型工程数据标定。

## 影响

- 延续体验级闭环优先的决策；界面方向改变，核心验收仍依据输入、动作、反馈。
- 旧 SpatialScene 保留，避免删除尚有价值的资产；全屏仿真入口改用 HmiCarStage。
- 节点动作失败和故障处理成功分开记录。
- 本轮仅保证车窗完整动作契约，其他车控能力需要逐项接入和验收。
