## 2026-10-12 · 模型接入与编排诊断

本周汇总（10月12日起） · 本机开发版 · 持续更新

- **新增｜DeepSeek 编排接入**：现有聊天模型菜单可配置DeepSeek官方服务，独立保存密钥，并在验证成功后选择模型；菜单与接口替身回归通过，真实账号已接入并完成六例调用。
- **改进｜编排故障定位**：记录每次编排的固定阶段、耗时和终止原因，批测保存完整SSE事件与结果，能区分缺配置、断流和生成失败；不将HTTP200当作成功生成。
- **修复｜Windows 图试跑启动**：隔离Node进程保留必要的SystemRoot，修复启动崩溃，实际离线图执行验证通过。
- **待验收｜真实生成与Windows全量回归**：已接入DeepSeek的六例真实批测可应用0/6（4例SSE错误、2例需要修改），需求规格、构图响应、连接契约和缺口反馈仍有阻塞；完整后端保留12项既有失败/错误。日常5175未更新；[证据与限制](../product/releases/2.8.0-dev.108/ACCEPTANCE.md)。

同周深归因补充：元数据重放已定位思考耗尽输出额度的截断；车窗最终图违反现行动作契约，缺口保留、计划纠错和澄清评测还需修复。方案已登记，原六例失败记录保留，尚未修改生产策略。

- **修复｜DeepSeek 输出与错误反馈**：已知型号按阶段提供输出额度，构图提高至32K并配套720秒整体期限；保留用户思考选择，截断与连接失败分开提示。
- **修复｜编排草稿与验收恢复**：损坏修复结果不再清空已识别缺口，澄清问题保留；合法计划纠错、动作配置说明和澄清草稿评测与现有契约一致。新增回归通过，真实六例复测进行中；完整后端仍保留原12项失败/错误。

第一轮修复后的32K冻结六例已结束：澄清规则通过1例，可应用0例，5例仍失败。成本检查发现目前全量提供节点目录、反复生成完整图，简单任务也承担较重上下文与思考；后续先核对能力选择及流程，不把增大额度当作可靠性或成本已解决。详细样本仍以本轮验收为准。

- **改进｜任务能力与上下文**：第一批在新分支实现本地候选召回、按需求加载契约与阶段视图；保留原始约束及真实来源，漏选不再等同平台缺口。离线结果见[验收](../product/releases/2.8.0-dev.109/ACCEPTANCE.md)。

- **新增｜十例编排验证**：用户明确本轮只测编排、跳过执行成功判断。按现有产物静态复评，文字、车窗、多轮状态、动态温控、长历史图5/7符合，全部6符合/2有编排问题/2无产物待评。原端到端4/7可应用及回放数据单列保留，新复评无额外模型/执行消耗；完整[结果](../product/releases/2.8.0-dev.109/TEST_CASES.md)说明范围与限制。

## 2026-10-05 · 文档阅读与工作台更新

本周汇总（10月5日起） · 本机开发版 · 持续更新

- **改进｜车模适配**：门窗改由车型对照表绑定，缺失部件省略动画且不影响共享车辆状态；保留当前车模和外观。真实模型回归及开发5173对照通过，旧候选风格已否决；新写实短名单尚待解决授权和文件验证，日常5175未变。
- **修复｜HMI 车控弹窗**：改为车机内居中，仅遮住 HMI；分类图标与文字左对齐，长设置独立滚动，关闭入口固定可见。深浅主题、窄容器、键盘和共享车控回归通过；仅开发5173，日常5175待安排更新。
- **修复｜日常与开发隔离**：日常Studio使用独立5175入口，固定前后端与独立项目数据，开发热更新不会经过日常编排连接。本机接口、数据复制和模拟断流回归通过，未重跑真实模型。
- **新增｜开发者文档网页**：可按目录阅读、搜索正文与代码、复制示例，并切换深浅主题。已通过功能检查，桌面精细视觉验收待补。
- **新增｜后台自动保存**：项目与对话在后台保存，支持刷新恢复；遇到保存冲突时保留本机内容。本机保存与恢复已验证。
- **新增｜MCP 工具接入**：Fetch 和 Time 支持查看参数、添加到画布、选择工具和编辑参数；首次运行自动安装。真实协议与图执行已验证，其他服务的安装配方仍待补齐。
- **改进｜模型与资源选择**：模型菜单支持搜索、供应商分组及实际支持的思考设置；组件库、模型库与 MCP 库的前三行统一为搜索加号、筛选、数量/来源；模型/MCP分页保持对齐。修复加号掉行，三库桌面坐标及组件库窄屏实测通过。
- **改进｜直接拖入画布**：模型/MCP移除独立添加按钮，卡片直接拖入；保留多工具选择、运行禁用及Alt+Enter键盘操作，修复窄窗口落点无法接收的问题。
- **改进｜用户消息气泡**：发送内容右侧显示中性圆角气泡，深浅主题均清晰，助手内容保持原样。以上三项仅更新开发版，日常5175尚未更新。
- **修复｜模板替换保护**：已有讨论或已保存的空画布也会确认替换；取消编排后隔离迟到结果，避免覆盖切换后的项目。回归与专用测试页面检查通过。
- **待验收｜节点右键删除**：已实现删除节点、清理关联连线和撤销最近一次右键删除。DOM 检查通过，真实页面操作验收待补。
- **改进｜编排前置检查**：在试跑前定位非法表达式变量和不存在的节点引用；测试计划明确每个用例独立会话、车辆和记忆，提供同用例写入/读取示例。
- **修复｜JSON 测试输入与错误定位**：输入节点支持直接对象、JSON字符串和text包装，提交测试计划即可定位缺字段或类型错误；输入错误与模型返回错误分开反馈，避免修错节点。
- **新增｜测试路径提醒**：检查可能等待回复却要求完成的步骤，以及可能依赖前一用例记忆的路径；提示同用例补回复和准备记忆，动态行为仍由试跑确认。
- **改进｜断言检查与恢复**：提交前从车控目录和图检查路径/类型，显示JSON原值与类型；支持受限等义纠错和预算内一次截断重试，增强state跨用例提醒。共享测试依赖保持隔离。
- **待验收｜AI 编排可靠性**：最终后端402项（9跳过）、前端相关80项（2跳过）及类型检查通过；七次真实对照2次可应用，复杂A-Claude 0/3未达目标。简单C-MiniMax 1/2、C-Claude 1/1；复杂图仍受契约修复、事件匹配与证据质量影响。日常5175未更新；[证据与限制](../product/releases/2.8.0-dev.106/ACCEPTANCE.md)。
