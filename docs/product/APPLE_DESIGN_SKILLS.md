## 项目选择优先

用户最新指令和明确限定范围优先，其次是该范围内已指定的 Figma/截图与已确认的项目设计。官方 HIG 用于参考与验证；社区 Skill 的默认值只用于补齐未指定细节。Skill 里的 inferred/speculative 是推断，不能当作苹果已确认的事实。

- HMI 保留纯黑背景、现有布局、SU7、顶部状态栏与 Dock。Figma 默认仅限既定顶部 `556:3522` 和 Dock `556:3524`；不能自动同步整个文件。
- 保留浅色透明背景的 Bloub 原版轮廓、眼睛与动画节奏。待机/思考/提醒由真实交互状态驱动；不自动轮播，通用弹簧建议不能替换原版角色动画。
- 按 dev.38 用户明确要求，通用字体采用系统无衬线、代码采用普通系统等宽，替代 dev.17 全局 Maple；保留既有主题；首页保留 Prism、已确认的玻璃项目卡片/搜索框、Logo 与像素标题、渐变和 Shuffle。不能因 Skill 的“浅色优先”“系统字体”“内容卡片用实色”默认值擅自替换。
- 首页项目入口、工作台和 HMI 都服务于实际操作，不自动改为滚动营销长页，不因社区模板要求增添固定滚动场景、设备外框或装饰效果。
- 项目操作沿用 Logo 菜单；不恢复新增保存工具栏或流程检查面板。dev.89用户明确要求后台自动保存与恢复，替代此前不自动恢复的约定；不得附带新增保存状态行或其他未经允许的界面。保留已有项目、模型与布局。
- 响应式文字交互和摄像头/环境驱动的主动交互继续作为目标。材质和动画不能代替功能闭环；dev.19 用户已授权本地录音与语音识别，dev.67 用户明确要求乘员提示由语音助手播报，现接入本机中文语音；不新增唤醒词或常驻监听。
- A2UI / AG-UI 仍是候选方案，内部组件或 JSON 结构不能宣称已接入开源协议。

## 每次实际界面修改

1. 先读取相关组件、当前截图/运行页面及本约定，说明本次修改的组件和预期效果。用户给定了具体目标即可执行；本约定不新增重复确认流程。
2. 按需读取对应 Skill 与参考，不整套套用默认外观。尺寸、间距、颜色尽量复用现有变量；不臆造未经用户确认的新设计系统。
3. 字体和间距用于形成清晰层级；玻璃材质需检查背景变化时的可读性，并提供透明度/对比度偏好的替代。保留已确认的玻璃卡片，不把“玻璃只能用于 chrome”当成删改授权。
4. 控件过渡应响应状态、允许中断、尊重减少动态效果，不阻塞点击/输入。动画不表现虚假的请求成功、车控成功或感知结果。优先复用现有 CSS/GSAP/Bloub 实现，按实际需求决定是否增加依赖。
5. 检查真实页面、窄屏与目标 HMI 尺寸，确认文字/眼睛不被裁切、焦点和点击行为正常。对变更做适当构建/交互验证；结果中区分已实测和未验证，不宣称未经测量的帧率。
6. 按项目现有流程记录需求、验收与限制。设计技能安装不等于产品功能发布；后续明确界面迭代再按版本规则登记。
