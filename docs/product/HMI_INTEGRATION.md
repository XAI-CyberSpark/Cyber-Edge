## 共享状态

registry：studio/src/data/hmiControls.json，后端副本backend/app/services/hmi_controls.json；一致性测试防止漂移。UI与节点都通过VehicleWorld.executeHmiControl；空调、门锁、原氛围灯、座椅位置映射既有car字段，其余状态进入car.hmiSettings。53项涵盖空调/除雾、座椅4区加热通风、遮阳帘、灯光、锁车偏好、显示、镜面/方向盘调节参数、驾驶偏好、安全及维护参数。前后端白名单同意后，图执行器仍再次验证输入，按实际提交值返回结果。页面开关、选项、滑杆和读取节点共用此状态，切换面板不会新建一份假值。

使用：车控节点选择“执行接口 → HMI共享控制”，选控制项/操作/目标值；也可绑定上游JSON字段。独立项目“SU7 HMI · 节点联动验收”保留可重复运行的例子，最后一节点读取实际温度。状态保留在当前仿真实例/场景快照内；刷新恢复初始状态，不承诺长期持久化。

## 扩展与能力边界

车辆控制success仅表示软件仿真状态提交。驾驶辅助、转向、再生制动、雨刷维护、镜面/方向盘等当前保存参数，不提供物理轨迹或对应部件动画。真实传感器、充电/BMS、续航、电话与在线服务仍待适配；未伪造里程、充电时间或物理动作。

旧[桌面组件](HMI_WIDGETS.md)保留可选HmiWidgetData/HmiWidgetAdapter，可接导航、媒体、图库与日程服务；失败、不可用、取消、迟到响应遵循已有契约。后续新增控制必须同时登记类型/范围、接入执行器、声明读回路径、加入正反例测试，不能仅增加一个可点击图标或默认成功响应。新设置不重写用户保存的工作流坐标或模型配置。

## HMI 交互与验证（dev.67，2026-09-27）

hmi.message 新输出生成独立 speechRequest，使用浏览器安装的本机中文语音；恢复快照不恢复播报请求。助手直接模型回复和确认执行结果也进入播报。开始录音、关闭面板或隐藏 HMI 停止音频；无语音/播放失败保留文字。后排画面打开成功后才发送风险提示。右侧从 RuntimeRunResult 事件建立报告，耗时含请求往返，不以模型分数推断准确率。 依据与验证见 [dev.67验收](releases/2.8.0-dev.67/ACCEPTANCE.md)。

## 车模描述与通用适配（dev.99）

维护日期：2026-10-06｜状态：开发5173实测通过，未更新5175。主依据：用户两步要求、[本轮验收](releases/2.8.0-dev.99/ACCEPTANCE.md)与实际源码。

[activeCarRig.ts](../../studio/src/data/activeCarRig.ts)导入当前 [rig.json](../../studio/public/models/su7/rig.json)；[carRig.ts](../../studio/src/domain/carRig.ts)验证结构、按声明选择节点/连通面片并烘焙几何；HmiCarStage只消费描述，不含SU7名称过滤或车体位置猜测。描述在构建时导入并经Vite热更新，不是运行时上传车型或自动发现资源的功能。

| 字段 | 约定 |
| --- | --- |
| version/id/model/modelSha256 | 描述版本1、车型ID、GLB路径、实际文件SHA256。改变GLB后必须重验组件索引与哈希 |
| source / environment | 来源、作者、许可及可选许可链接；可选环境HDR。授权未知应照实记录 |
| rotationY / componentPrecision / splitNodes | 烘焙方向；连通顶点合并小数精度；需拆分节点名。components按烘焙后非索引三角形首次出现顺序编号 |
| selectors | Three.js加载后的node精确名字；descendants包含子树；可选components选择连通块。不是原始文件名模糊搜索 |
| doors.fl/fr/rl/rr | selectors、烘焙世界坐标pivot、旋转axis/angle（弧度）、门局部hotspot、相机可见side |
| windows.fl/fr/rl/rr | selectors、相对门组/固定组的travel向量；clippingPlane为世界平面[nx,ny,nz,constant]；多个网格可共同构成一窗 |
| lights / trunk | 前灯、尾灯、左右转向灯、后备箱选择器，可null/缺省。当前只解析能力，尚未新增灯/后备箱动画执行器 |
| bodyColorMaterials / appearance | 车身可变色材质名单及明确的材质/节点外观覆盖；没有新增用户选色界面 |

SU7保持四门四窗全部命中和原有青绿车漆、玻璃、水面、相机、锁车关门行为；灯组和后备箱暂未验证独立绑定，描述明确置null，保持原有静态显示。既有SU7来源与环境图授权状态没有因新增描述变更。

缺省部件或选择器缺失时，不生成该门热点/该窗动画；命中不完整的门退回静态位置，不制造半扇可动门。模型状态仅决定渲染能力，不写VehicleWorld、不删除其四窗状态、不改变车控接口。测试中的CarConcept只有fl/fr；rl/rr仍可正常更新VehicleWorld，但该模型不显示后门/后窗动画。本轮采用用户允许的“省略动画”降级，不增加重复警告。
