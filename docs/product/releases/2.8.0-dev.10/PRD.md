# 座舱主动与响应式交互

2026-09-15 / 2.8.0-dev.10 / 开发中、未发布。

用户确认的目标：HMI 承载乘员文字输入和场景主动反馈；顶部助手参考用户提供的蔚来深色、圆角、细边缘光面板。保持 dev.9 蓝灰磨砂卡片、底栏和 SU7，不恢复被撤回的绿色布局。

## 需求
- R1：顶部可展开收起的文字助手，支持模型问答；不接录音、ASR 或声音播报。
- R2：以受控组件展示回复、追问、车控建议、实际结果；不执行模型生成的任意代码。
- R3：文字提出车窗和空调操作，用户点击卡片确认后调用共享车辆执行器，结果依据实际状态。基础手动控制不依赖模型在线。
- R4：摄像头场景流程已有的 HMI 事件主动展示。重要提醒优先，持续事件更新同一位置，不清除普通会话；收起不代表风险解除。此轮不增加持续摄像头采集或新的识别模型能力。
- R5：保留会话上下文；模糊指令由模型追问。超时、无效结构、未知操作不得执行；失败可重试。
- R6：A2UI 为候选方案，先验证协议与模型输出兼容性，再决定是否引入；不得将内部组件格式宣称为 A2UI 兼容。

## 验收
问答、车控确认、故障反馈、主动告警与普通对话共存、告警收起/更新、长文本和窄屏、模型离线、无效模型输出、重复点击、回滚完整性。
