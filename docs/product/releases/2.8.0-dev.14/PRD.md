# Figma HMI 顶部状态栏与底部 Dock

版本：2.8.0-dev.14，开发工作区，未提交、未发布。

用户明确要求仅同步两个栏位。Figma 文件 pLWFNEoqZRfNPbASDtOiKy，父画板 556:3521（驻车），顶部 556:3522、Dock 556:3524。两组件原始尺寸均为 3456 × 180；父画板宽 6912，右侧附带画面不属于本轮同步范围。

设计来源：https://www.figma.com/design/pLWFNEoqZRfNPbASDtOiKy/?node-id=556-3521

- 顶部：左侧时间、预估续航与 PRND，右侧消息、Wi-Fi、互联图标。
- Dock：首页、车辆、导航、应用、左温度、风扇、右温度、前/后除雾、媒体。
- 使用 Figma 原始导出图标与封面，字号与栏位间距适配当前 HMI 宽度。保留现有黑色中间区域、助手、SU7 车模和面板逻辑。
- 桌面继续预留现有助手位置；HMI 容器宽度不超过 900px 时，状态内容下移至助手下方防止重叠。Dock 极窄时水平滚动保留全部入口。

能力边界：现有温度模型为全舱单温区，两侧控件联动且 title/可访问名称说明，不扩展模型。续航没有数据，显示破折号而非设计样例 45 km。PRND 根据已有速度表示仿真状态，不表示新增变速箱模型。Wi-Fi 无状态源，只保留图标并标注未接入；互联打开现有手机面板。除雾无对应能力，禁用并提示未接入。媒体显示实际模拟曲目或未播放，封面沿用设计示意图，未伪造播放进度。

验收：视觉仅按两栏设计核对；真实状态更新、导航/车控/应用/媒体入口可用；中间内容与数据结构不受修改。不接入录音、识别、播报或外部应用。
