# Bloub 助手动画移植：第一阶段

版本：2.8.0-dev.15。日期：2026-09-15。开发预览，待视觉验收。

用户要求将 https://bloub.vercel.app/#etat=alert&stop 的形象及动画用于 HMI，并确认“按照你的思路来吧”。约定先独立对照，用户确认还原效果后替换 HMI，再连接真实交互状态。最终目标仍是文字响应式交互和摄像头/环境事件触发的主动交互；本阶段不增加录音、识别或播报。

- REQ-01：保留 14 种公开动画与内部 swirl；保留形变、眼睛、粒子、轨道及过渡参数。
- REQ-02：原版黑色浅底与 HMI 奶油色黑底同帧对照；支持黑色形象加浅底。
- REQ-03：状态选择、原序轮播、暂停、重播、时间滑条和 48–256px 尺寸预览；后台暂停与卸载清理。
- REQ-04：独立 /?preview=avatar 地址，不改当前 HMI、Figma 顶栏/Dock、SU7、模型与项目数据。

验收场景：打开页面 → 选择警示 → 比较配色与同步形变 → 轮播全部 → 暂停/拖动时间 → 切换 72px → 提交视觉反馈。代码检查不能代替体验验收。

本阶段未接鼠标跟随、网站入场视线脚本和定制器，引擎对应能力保留。后续按 HMI 需求确认，不声称整站交互全部迁移。代码与来源见 studio/src/vendor/bloub/SOURCE.md、LICENSE；上游 MIT 声明不涵盖其模仿的 x.ai 设计。

## HMI 正式入口接入补充（2026-09-15）

用户已明确授权直接替换「CYBER 助手」左侧四角星，不再以独立对照页作为交付终点。此补充沿用 dev.15 动画移植迭代。

保留原 27px 占位及文字/容器间距，使用 40px SVG 与完整原版 viewBox，使主体约 25px、装饰有余量；浅奶油色，周边透明，眼睛底色跟随展开/收起的容器底色。只在该位置替换图标。

优先级：可见 warning → alert；文字 pending、车控 executing 或 hmi.agentStatus=processing → thinking；其他可见主动提醒 → notify；其余 → idle。提醒收起/清除后依据当前请求状态回到思考或待机。保留原版呼吸、眨眼及平滑过渡，不轮播；减少动态效果偏好使用静态代表帧。页面隐藏/组件卸载停止 RAF。

无录音、识别或播报新增。原有展开、文字输入、建议确认及执行反馈保留。
