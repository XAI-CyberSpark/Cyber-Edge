# HMI 细节优化

用户授权：先使用已安装 Apple Design Skill 优化 HMI。

## 观察与范围

1280×720 实际页面：助手展开遮住部分顶部状态；Dock 温度箭头点击区域过小；面板与输入、操作层级可以更清楚。

- 保留现有纯黑布局、Maple 字体、SU7、Figma 图标顺序和 Bloub 原版节奏。
- 助手采用黑色分层与克制材质，优化文字、留白、输入焦点；展开避开状态栏，内容超长可滚动。
- Dock 操作区至少 44 CSS px 高/宽；尺寸不足时横向滚动，不能隐藏能力。44 CSS px 是 Web 实现选择，不等同原生 pt。
- 车控弹层与助手统一圆角、间距、焦点及短暂按压反馈。减少动态效果保留无位移反馈；减少透明度和增加对比度时采用实色。

## 完整体验

展开助手 → 输入/选建议 → 收起后重开仍保留文字 → 请求及车控确认沿用现有实现；打开车辆控制 → 调温 → 查看 Dock 共享状态 → 关闭回到原入口。

非目标：首页、工作台外壳、项目/模型数据、协议接入、录音/识别/播报、Bloub 动画重做、真实车辆安全验收。不修复此前独立记录的工作流模型兜底问题。
