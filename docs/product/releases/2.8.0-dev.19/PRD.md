# HMI 本地语音输入

用户确认接入 SenseVoiceSmall INT8 + sherpa-onnx。此授权更新此前“本阶段不增加录音和ASR”的范围；仍不增加语音播报、唤醒词、常驻监听或独立展示页。

完整场景：点击现有助手麦克风 → 明示录音状态 → 点击结束（最多30秒）→ 本地转写并填入现有输入框 → 可编辑后发送 → 原助手生成建议 → 用户确认 → 实际仿真状态反馈。取消不发送；已有输入保留并追加识别结果。

约束：仅用户主动点击请求麦克风，关闭助手/切换页面/隐藏标签或取消时释放设备与请求；音频只在内存，不存盘、不上传第三方。模型独立于原OpenSparX意图模型，失败不得使用假文字/假成功。保留纯黑HMI、Maple、SU7、Figma Dock与Bloub原动画；聆听使用原wide姿态，转写使用thinking，warning优先。固定依赖、模型来源与校验值，提供Mac/Windows部署说明。

异常：拒绝权限、无设备、模型缺失、服务失败、静音/过短、超时、重复点击、取消后迟到响应、窗口隐藏。首版分段非流式ASR，不宣称逐字实时。

## 同轮界面收敛

顶部助手按用户截图收敛为圆角入口：Bloub 形象、CYBER 助手、右侧麦克风；移除欢迎标题/说明、快捷建议、副标题、展开箭头与常驻脚注。录音保持收起并使用原 wide 聆听姿态；转写后才展开可编辑文字，保留原回复与车控确认。点击标题仍可手动输入；Escape 取消，权限申请/转写中再次点击图标取消；错误按需显示。
