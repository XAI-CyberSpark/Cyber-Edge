## 已知限制

1. 这是车辆行为仿真，车窗时长与玻璃几何不是来自工程标定；不证明真实车型精度。
2. 注入天气后需要主动运行工作流，未实现持续事件订阅。
3. 完整执行反馈契约先覆盖车窗；其他历史动作尚未统一接入。空调和锁车只变更本地状态。
4. 导航只显示目的地，媒体只显示状态，后排画面请求不接视频流。
5. 模拟状态在当前工作流会话内有效，不持久化到工作流文件；刷新或切换工作流需要重设测试条件。
6. 运行记录反映执行经过，不等同于每次运行自动生成了完整验收结论。
7. 此前用户对后端和其他功能的修改未在本轮完整回归。
