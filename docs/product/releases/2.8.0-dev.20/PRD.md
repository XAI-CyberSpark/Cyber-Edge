# 网站访问密钥

2026-09-23，用户要求首页自动弹出使用密钥窗口，并明确密钥用于网站访问，不是模型API Key。

- 新打开/刷新页面自动显示输入弹窗，未验证不挂载项目和工作台；同一次页面内导航不重复要求输入。
- 后端验证成功后进入原首页。输入默认隐藏，可切换显示；支持Enter、加载态、错误/超时反馈。遮罩和Escape不能跳过。
- 现有项目、HMI、字体、Prism和项目布局保留。会话过期后覆盖弹窗，保留已挂载工作区以便重新验证继续使用。
- 网站密钥独立于云模型凭据。密钥由服务端生成并仅保存本机，前端只持有HttpOnly会话Cookie；不把密钥保存到localStorage或源代码。
- HTTP接口与Telemetry WebSocket握手均验证；公开健康检查与验证接口保留。加入错误尝试限流、来源检查和开发服务器文件范围限制。

本轮为单机共享密钥入口，不新增账号、角色、发码管理或云端部署。静态前端资源仍可下载；数据和业务接口受后端保护。
