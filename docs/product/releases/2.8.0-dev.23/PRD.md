# 图片自动处理

2026-09-24，dev.23 开发迭代。用户要求修正“5 MB/格式”合并拦截，允许大图自动处理。

范围：仿真输入与单独测试模型两个入口。PNG/JPG/WebP原图不超过25 MiB，超过原5 MiB不直接拒绝；最长边不超过2560且不超过4 MiB的小图保留原始字节，其余按比例缩放、不放大，以JPEG逐级质量/尺寸压缩至4 MiB以内。压缩路径透明区域填白；原文件不修改，预览与提交使用同一处理结果。

分别提示空文件、格式不支持、HEIC/HEIF、原图过大、解码失败和压缩失败。以文件签名识别格式，兼容操作系统MIME缺失；大于8000万像素显式报错。HEIC转换尚未接入，不宣称已支持。

不改变模型接口、既有项目、HMI布局、自动语音交互或后端模型能力。验收：原超过5 MiB图片可预览/待发送，比例正确；小图不重编码；错误区分明确，失败不发送。

## 同轮修复：图片上传后的推理

修复真实图文请求超过4096上下文导致的503。模型支持128000上下文，本机启动默认改为8192，保留环境变量覆盖。仅识别已知超限错误并展示安全的输入/上限计数；其他失败仍停止执行。验收包括超过原4096的真实请求和图文推理，不以模拟成功替代。
