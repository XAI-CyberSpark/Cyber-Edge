## 行为边界

抽帧在前端完成，原视频不上传；图片帧按工作流模型路由发送推理。识别完成后等待2秒再采样，可能遗漏短暂行为。视频回放不是实时摄像头。触发依据时间与当前播放时间可能不同，二者同时标明；不自动声称风险解除。事件只保留当前会话。

## 用户纠正后的体验重做（同一开发版本）

主路径重做为：后排画面来源 → 开始场景测试 → 自动监测 → 风险时中控展示持续视频。单张图片与结构检查折叠到高级调试，默认无图片聊天输入、补充说明或双上传入口。选择录像后默认循环，可以在回放设置关闭。正常/未知观察不推送中控图片和文字卡片，风险展示视频；收起后同一连续风险不重复弹出，正常观察后再次出现风险或重新开始测试可再次提醒。新版替代前文“整次回放仅弹一次”策略。
