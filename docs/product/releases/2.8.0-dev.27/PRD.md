# 组件库资料导入

版本：2.8.0-dev.27 / 2026-09-24。状态：本地实现与本轮验收完成。

目标：产品经理导入车企接口资料，获得有来源依据的能力清单，分类浏览并检查接口、参数、限制和待补充信息。保留原有画布组件与模型。

- REQ-01：顶部导入按钮，左侧五类分组，列表可搜索、按资料/内置筛选，点开详情。
- REQ-02：PDF（文字版）、DOCX、MD/TXT、JSON/YAML、CSV/接口定义及ZIP资料包；不执行二进制 SDK。单文件8 MB、解压30 MB、100项、文字10万字符、PDF150页，超限明确失败不截断。
- REQ-03：OpenAPI/能力清单直接解析；其他资料经用户勾选使用既有编排模型识别，展示服务提供方。逐项保留原文证据，缺失不补造。
- REQ-04：预览勾选确认后持久保存；重复导入提示；失败不入库；关闭预览不入库。
- REQ-05：资料能力的接入与验证状态独立，均为未接入/未验证。现有组件保持拖拽；新接口适配、实车探测、自动场景编排使用导入目录不在本轮范围。

不承诺完整识别所有资料/整车能力、模型准确率或实车运行；SDK包需要配套可读资料。布局按用户选择的管理视图，使用已有主题与Maple字体。
