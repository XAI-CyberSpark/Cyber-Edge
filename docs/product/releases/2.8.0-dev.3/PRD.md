# 儿童关怀：图片—节点流—HMI

版本：2.8.0-dev.3，开发中；延续既有 SU7 和左右仿真布局。

## 目标
用户上传儿童/座舱图片，经当前工作流的视觉模型、结果校验、条件分支，得到 HMI 实际响应。

- REQ-001：测试台一键新建儿童关怀流程；保留原流程，节点可编辑。
- REQ-002：图片直接进入所选视觉模型，不选择摄像头视角、不从文字或预设结果伪造识别。
- REQ-003：模型返回 normal/risk/unknown、数字置信度、动作与观察依据；字段无效停止执行。阈值默认 0.85，可修改判断节点。
- REQ-004：明确风险显示 HMI 提醒与本次图片；正常温和反馈；低置信度/未知提示无法判断。右侧与 HMI 同源反馈。
- REQ-005：失败显示真实错误；单张图片不能代表实时流，不因计时结束声称风险解除。

范围不含自动车控、真实语音播报、连续视频、风险跟踪、识别精度承诺。普通儿童图片不必触发警报。默认模型名 Qwen2.5-VL-3B 为待配置模板值，必须与服务中实际部署模型一致。

流程：仿真 → 测试台 → 新建儿童关怀 → 审查视觉节点模型与提示词 → 仿真右侧上传并发送。旧的已保存儿童流程不会自动重写，需要重新生成模板；旧提示词若不符合新 JSON 契约会失败。
