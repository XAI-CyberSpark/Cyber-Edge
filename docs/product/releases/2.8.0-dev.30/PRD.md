# 导航面板统一布局

用户最终要求：五个面板统一占画面的三分之一宽，从顶部覆盖左上“工作台”，右侧工作区继续可见。

- 五个面板统一工作区顶端/左边界/全高外壳，保留左侧导航用于切换。
- 共用72px标题栏、图标/标题/说明层级、关闭位置与24px内容边距（窄屏16px）。
- 项目库、场景库在窄侧面板使用单列卡片；组件分类与表格保留；诊断卡片使用统一内容区域。
- 关闭/Escape恢复焦点；底层画布/对话/仿真保留，右侧可见工作区保持可交互；拖放组件时可临时返回画布。
- 保留导入、搜索、MCP目录、项目打开/删除确认、场景载入、状态查询等原有能力，不新增后端能力或改写项目数据。
