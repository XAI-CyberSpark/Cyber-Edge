# 持续互动与节点执行契约

用户授权：2026-09-24「开始优化」。交付 Mac 本地可运行原型，以朵朵生日航海贯穿验证。

- REQ-1：新模型节点显式声明文字、结构化数据或受控动作。数据字段经过类型校验再传给下游；不默默丢字段或让数据冒充执行指令。
- REQ-2：成功和失败路径分离；错误回复送达但原失败不能被标记成功。
- REQ-3：持续互动节点使用可复用阶段配置。模型可以逐章创作，平台负责等待、答案匹配、进度、线索和完成。支持提示、暂停、继续、跳过、退出、重开；失败不推进，事件去重。
- REQ-4：保留现有聊天框。阶段/到达从聊天明确模拟，进度存当前页面会话，项目间隔离；刷新不恢复。配置修改后要求明确重开。
- REQ-5：模型创作不限制故事题材；未接能力只能作为待接方案。保留儿童关怀照片到独立视频闭环。

非目标：真实导航/定位、语音播报、图形小游戏、实车执行、模型准确率承诺、跨刷新/跨设备进度、任意脚本游戏。第一版一个工作流一个互动实例，输入直接进入互动，完成后才走下游。

验收：启航→隐去答案的谜题→错误/提示/正确→线索只发一次→暂停期间不推进→继续保留题目→下一章→到达收尾；另用科普题验证复用；模型失败/取消/重复事件不损坏进度；受影响儿童关怀回归。真实模型与受控测试分别记录。
