# 场景编排验收基准

用户确认建立20条代表场景的验收标准，先覆盖儿童关怀与生日航海。交付可读案例、机器可执行基准、真实引擎回放和独立的内容评审记录。验收草案由现有用户意图整理，待共同校准，不能自称用户已逐条确认。

- REQ-1：20条有原始输入、必须结果、禁止行为、预期处理和人工标准的案例，覆盖正向、异常、能力缺口和澄清。
- REQ-2：生成模型只收到原始用户需求，不接收验收答案、参考图。不同模型使用同一案例、重复次数和生成链路。
- REQ-3：客观检查基于独立规则与真实引擎执行；注入识别/视频/车辆回执，不接真实设备，不伪称视觉模型准确率。
- REQ-4：人工内容评审绑定案例与生成结果校验值，缺少评审不可宣称完整通过。失败类型、运行限制、缺少凭据分开记。
- REQ-5：原始结果不修改、不保存到用户项目；每次报告独立存档，规则/代码版本变化不直接比较。

非目标：扩展右侧聊天界面、用同模型自评分替代验收、保证20条全部通过、自动为不可用功能编写执行代码、接通实车。
