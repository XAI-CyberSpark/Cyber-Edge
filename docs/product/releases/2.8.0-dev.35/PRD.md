# 场景共创聊天布局

问题：输入框发送后仍保持高位，长字段撑出横向滚动条，聊天区占用与边界杂乱。

范围：仅编排模式右侧 ChatPanel。输入框随内容和面板宽度自适应，空值收回，长文限制高度；聊天记录隐藏滚动条并保留滚动，修复长字段/代码/表格溢出；整理内边距、焦点和发送按钮。保留 Maple 字体、主题、模型选择、发送及生成流程。

验收：单行、多行、清空/发送后收缩、320px窄面板、长消息/代码/表格、键盘滚动和现有模型选择/生成回归。


同轮补充（2026-09-25）：双方头像移除，用户消息采用右对齐中性气泡，助手回复左对齐无底色并使用完整正文宽度；思考中采用行内状态。构建通过；模拟长消息页面确认头像数量为0、正文背景透明、无横向溢出。保留自适应输入与生成逻辑。
