# 节点定义 v0.1

用户要求：先写清每个基础节点的职责与边界、输入输出、实现来源、运行条件、失败处理和验证依据，作为可靠 AI 编排的前提。

交付：可共同评审的 [节点定义](../../NODE_CONTRACTS.md)，统一场景/子流程/基础节点/实现绑定；14项基础能力及现有16种运行节点映射；儿童关怀与生日航海示例；证据格式与落地顺序。

范围：产品与接口定义草案、代码现状核对。非目标：改界面、重写提示词/执行器、迁移用户项目、调用付费模型、宣称准确率或实车可用。创作空间保留，未实现能力可提案但不可伪装可运行。

验收：六项契约齐全，现有类型无遗漏，新设计与实际实现明确区分，示例使用同一粒度，测试证据有范围说明，文档可访问。用户语义与体验评审待完成。
