# 高通 AI Hub 模型目录筛选

用户已明确：接到组件库 → AI模型分类。

- REQ-1：读取高通官方发布目录，按来源、用途、领域、芯片、运行时与是否有量化版本组合筛选；支持搜索、分页、详情和官方链接。
- REQ-2：保留已注册模型与原有AI组件的添加能力；高通条目仅供选型，标记未接入，不混入运行模型接口、不下载权重或触发部署。
- REQ-3：目录版本、同步时间、缓存与失败可见；首次离线使用有来源的随包快照，支持手动刷新；未知信息不伪造。
- REQ-4：检查正常/空/失败/过期缓存、组合筛选与既有组件回归；构建及宽窄页面验收。

目录范围为官方 AI Hub Models 发布清单；网站额外渠道模型不声称全部覆盖。芯片字段表示官方已做性能测试，不能作为本设备可运行保证。Cybertools量化、编译、部署留待后续独立集成。

- REQ-5（用户截图及后续修正）：模型使用场景封面、名称、简介和用途标签卡片；组件库保持页面三分之一桌面宽度，模型/MCP每行两张且尺寸一致。完整设计规范由用户后续继续调整。
