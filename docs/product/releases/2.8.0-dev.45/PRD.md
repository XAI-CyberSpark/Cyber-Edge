# HMI车模侧面打光

2026-09-25｜[项目入口](../../../README.md)

用户希望按所附旧HMI截图恢复柔和侧面打光。范围仅车模灯光与舞台氛围：左前方冷色主光、较弱顶部及侧面补光、局部柔和光晕。保留当前布局、相机、车模材质、车门/车窗交互和黑色地面倒影；参考图的旧面板/布局不在恢复范围。

验收：实际车模看到车头与侧面明暗层次，局部光晕不遮挡交互，构建通过。无新增业务接口或状态。

## 2026-09-26 用户修正

用户不满意侧光，认可现有水中倒影；新参考要求车后低位蓝色氛围向黑色渐隐。此项替代本轮左侧叠加光晕方案，保留水面反射/波纹、相机、模型材质与布局。

### 倒影与地平线回归修复

用户反馈倒影消失、地平线偏高。恢复可见车身/车轮倒影，降低并柔化背景交界。保留水面反射/波纹参数，不调整相机、车模材质和HMI布局。

### 最新位置修正

用户撤销背景底边柔化，并要求车模向下20%。移除底边smoothstep；以车模投影包围盒高度为基准，将相机投影整体下移20%（舞台高度20%的初次预览会裁掉大部分倒影，已改用车模高度），保持车辆比例、观察角度、车门热点与倒影的空间关系。
