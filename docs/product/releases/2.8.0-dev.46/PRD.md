# 节点生成与不可执行草稿

2026-09-26｜2.8.0-dev.46｜本地开发迭代

用户输入自拍识别、衣物配色、氛围灯调节与中控姿势推荐后，画布保持空白。需要区分“无法解析的结果”“可查看的设计草稿”和“通过生成检查的候选”，不能因为缺能力就隐藏整张图，也不能把设计草稿伪装成可执行功能。

范围：普通工作流结构化输出、schema范围内格式兼容、准确字段错误、澄清问题与草稿共存、空画布展示与既有图保护、前后端执行阻断。保留原始目标与缺口，禁止用无关动作替代。

验收：结构完整且连线引用有效的未通过候选可显示；错误结构不能复用旧候选；既有普通节点不被失败结果覆盖；保存再加载草稿仍不能调用模型或设备；确认问题不导致空图；模型、真实视觉和真实执行能力分别记录。

非目标：接入通用图像识别、氛围灯控制、实车；不承诺任意输入均生成可靠体验。
