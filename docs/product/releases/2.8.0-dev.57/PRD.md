# dev.57 模型编排与执行反馈闭环

2026-09-27｜实施中。承接已确认的dev.56方向与用户API模型搭建通用节点目标。

让正式场景构建器获得真实GraphEngine执行反馈，按失败节点和断言结果修复候选。场景名称、题型、事件与预期均在测试数据中，不作为执行器分支。创作模型、节点执行模型、仿真动作与测试注入来源分别记录。

本轮建立通用测试计划、无界面运行宿主、受控能力调用与有限反馈修复。测试计划有独立输入序列、状态/动作/输出断言；同一运行时支持状态等待、分支、模型输出和HMI动作。缺少适配器报告未验证；不能把未验证候选说成运行通过。生成器提供的断言只证明其计划能执行，不作为用户意图的独立验收。

后续在此基础上继续多模态、外部工具、循环/持久化等通用能力，不因本轮完成缩小原始目标。已有项目保留兼容，不自动迁移，不改视觉布局。

验收：不同主题同一执行器；错误反馈触发真实修复；模型调用来源可核对；失败/超时/取消不报成功；未知类型与副作用不静默跳过；现有图回归通过；代表性真实API生成与运行分别留证。
