# 场景仿真与模型调试分离

版本 2.8.0-dev.6，2026-09-13。用户确认的新一轮体验调整。

- REQ-001：场景仿真展示当前工作流、流程模型及输入要求。儿童视觉流程以图片为主，文字为可选说明；只执行当前工作流，不自动替换模型或绕过流程聊天。
- REQ-002：模型节点提供独立测试标签，可发送文字及图片，显示模型原始回复。直接调用节点选定模型，不附加场景提示词、不运行 GraphEngine、不更新车辆状态；每次请求独立。
- REQ-003：输入验证、重复提交、错误、取消与卸载保护；保持原场景、模型资源、车模与工作区修改。

非目标：全车机助手路由、多轮聊天、连续视频、真实车辆控制。
