# dev.60 可再次等待的通用图

2026-09-27｜本轮已应用主工程，列明范围已验证；剩余能力见验收。沿既有通用图方向补齐事件驱动的循环：wait.repeat=true允许下游路径返回该等待节点，下一次用户事件启动新一轮，保留会话state与此前已提交动作。业务继续/退出规则仍由logic和连线配置，不引入场景名称或全局退出口令。

结构要求：每个环路必须经过声明repeat的wait；无需重新等待输入的自动计算环路本轮尚不接入。循环重置只涉及重入点之后的节点，不重放上游初始化/动作，清理上一轮输出和分支状态；退出分支可以正常完成。暂停/恢复、去重、错误重试、循环次数/事件/执行预算必须有效。持久化不是本轮交付。

验证：不同场景的手写机制测试、原DAG回归、API模型自主构图以及调用方固定多轮/退出验收。候选运行证据必须区分注入测试与实际API。前后端契约一致，既有项目保持原语义，浏览器和更复杂嵌套并行语义分别记录。
