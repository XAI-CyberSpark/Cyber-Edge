# dev.63 实际输出内容核验

2026-09-27。dev.62真实API讲解候选通过形式断言，却出现无实质内容的句子；Hermes报告content_review一直为not_run。目标是在既有图执行、锁定验收和有限修复架构内，增加基于实际输出的内容/意图门槛。

Hermes运行通过后，以配置的编排模型在独立上下文检查实际文字和结构化执行证据，不提供图修改/设备工具。逐步覆盖所有已运行用例；问题必须引用用户原话和真实字段片段。结果与当前图版本、执行证据绑定；修改使旧核验失效。核验缺失、引用无效、预算超限或服务错误不能放行，不能通过减少需求或改锁定测试修复。

不以全局关键词、固定场景模板或主观风格判定质量。模型辅助核验不是独立事实验证，不代表所有未来输入、视觉精度或端侧部署通过。本轮主路径为Hermes；既有bounded生成器的模型审查保持原契约，不冒充使用相同新核验协议。主界面和八工具边界保持。

验收包括：运行通过但内容失败时禁止应用；错误/不完整审查关闭放行；图改动及新试跑使旧核验失效；用户约束/证据引用与逐步覆盖校验；锁定测试不变。真实API检查历史合成失败输出及满足相同约束的内容，再验证模型根据内容问题局部修复并复验；失败记录保留。
