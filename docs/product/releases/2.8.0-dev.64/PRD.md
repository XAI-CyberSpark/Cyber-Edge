不保证语义或事实正确，不新增场景模板/全局关键词，不改变待授权输入过滤。原输出契约不放宽，新增前后端参数检查和可核对的尝试记录。跨至少两种用途验证成功修复、耗尽、取消及副作用边界；真实API与注入故障明确区分。
