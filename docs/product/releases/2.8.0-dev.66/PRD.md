# 仿真切回编排不中断请求

2026-09-27｜2.8.0-dev.66｜开发迭代

用户要求：测试时离开仿真页面、回到同一场景的编排页面，正在处理的请求不应终止；返回仿真可以查看处理进度与结果。

范围：同一个打开的场景，编排/仿真只切换视图；请求、聊天记录、附件处理与仿真状态保留。运行中返回不能重复提交；隐藏时完成后应追加一次结果，失败时保留真实失败提示。适用于通用流程及旧节点流程，不按儿童关怀等场景名称特判。

边界：切换到另一项目、关闭场景或退出工作台仍沿用取消与隔离逻辑。浏览器刷新/关闭后的后台运行不在本轮范围，现有持久化恢复规则保持。

方案：FlowCanvas与VehicleSimulator本来保持挂载；修复只在模式切换时卸载聊天面板的问题。新增SimulationInputSurface保留面板实例，仅切换display；隐藏时不滚动页面，返回时恢复聊天滚动。无需新增服务端后台任务或改变执行器契约。
