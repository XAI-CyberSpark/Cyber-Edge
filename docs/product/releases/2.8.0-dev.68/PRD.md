对照场景：主题短句、保存并恢复灯光状态、缺少真实机器人接口的设计。相同需求、固定调用方测试（前两项）、模型、版本和预算；禁止人工改图后回填首次成功率。比较可运行完成、正确标注设计、人工介入、耗时和实际用量。网关费率/账单缺失时金额未知，不套用官方直连价格。

本版交付后端编排机制和可复现报告；保持原 UI 流程与 HMI。能力预检读取实际契约和配置，最终执行为隔离模拟 HMI + 真实 API，不能证明实车连接、浏览器音频或任意未来场景。
