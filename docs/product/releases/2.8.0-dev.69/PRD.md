# 本地推理等待、取消与视频展示

2026-09-27｜开发中、未发布。依据：用户接受按模型设定期限、可取消、明确超时；随后要求移除视频浮窗“演示回放”和视频内“豆包AI生成”。

解决前端60秒而本地服务180秒造成的提前失败。统一策略文件指定OpenSparX服务期限180秒，其余前端默认60秒；客户端额外5秒用于接收错误。JSON修复共用同一节点期限，不自动重试识别。取消当前本地推理连接，停止后续节点；底层GPU当前运算可能需到取消检查点才释放。

本地视觉输入保留原有最长边2560与原始图片；缩到1280的实验改变风险判断，已撤回；不改风险分流阈值，不使用模拟结论兜底。保留现有30分钟模型驻留，不另加自动预热请求。

发送按钮在执行时变为取消；原状态行显示已耗时，失败原因直接显示。保留原页面布局和字体。视频浮窗删除来源叠字；用户指定录像生成去水印副本，原始素材备份，右侧仍记录演示来源。

验收：超时及断连关闭本地上游；图片缩放不覆写原图；取消不执行后续；同图实际推理与视频弹窗；视频无码字。云端提供商终止计算、实车实时安全、任意图片识别准确率不在本轮已验收范围。


界面补充：测试输入框发送/取消按钮使用统一紫色主题。


语言入口补充：在主题切换按钮正上方添加中英文切换图标，复用 AppContext 既有语言状态。
