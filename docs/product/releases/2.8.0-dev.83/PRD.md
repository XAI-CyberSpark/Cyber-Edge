# 编排入口未交付的契约恢复

2026-10-03｜2.8.0-dev.83｜本地验证与截图原句真实MiniMax复验通过｜[主文档](../../../README.md)

用户截图：MiniMax-M3 对“我想为长途出行设计座舱互动体验，请先和我讨论乘客、旅程阶段与互动方式。”结束回复，却未提交入口结构化决定。截图证明终止在需求讨论阶段，未保存对应上游响应，不能断言是工具未调用还是字段被拒绝。

本轮目标：修复已复现的普通文本结束后没有契约恢复机会；保留只读入口、结构化build交接和原图保护。沿用ADR 0009，不将普通文字推断成讨论成功或构建许可，不增加场景关键词规则。

- REQ-001：成功结束但未交付时，反馈具体交付要求并继续同一只读对话，入口累计最多3次completion，与原团队共享24次/480秒。
- REQ-002：异常、取消、失败不当作普通文本重试；预算耗尽仍受控失败，不开放构建工具。
- REQ-003：入口诊断记录真实交付尝试/拒绝及累计调用数，不包含模型原文或密钥。
- REQ-004：本地模拟、固定真实SDK协议与真实MiniMax分别验收；真实外发已由用户“重新发送”授权，截图原句复验通过。既有项目不参与测试、不保存。

非目标：视觉改版、第三方SDK修改、场景执行门槛变化、已有项目重写。
