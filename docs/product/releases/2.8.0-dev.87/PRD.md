# 场景模板替换确认与编排取消

2026-10-05｜2.8.0-dev.87｜状态：已实现并完成所列本地验收｜依据：本聊天用户确认使用 Studio 内弹窗。dev.86 为并行「设计规范」修改。

目标：编排中点击场景模板不再立即覆盖项目；确认后停止本轮，阻止迟到结果改写。已有画布先确认替换，仅全新、无对话且空闲的空白工作流直接载入。项目名称、聊天与模型选择保留，旧场景规格、待应用结果和路线元数据清除。

| 需求 | 行为 | 验收 |
|---|---|---|
| REQ-001 | Studio 内确认框，取消为初始焦点；取消/Escape 不改画布和请求 | TC-001 |
| REQ-002 | 确认停止后取消连接与 reader，立即失效旧结果；新请求不被旧 finally 清理 | TC-002 |
| REQ-003 | 非空画布、已有聊天或已保存项目都先确认；仅全新无对话的空白空闲工作流直接载入并提示 | TC-003 |
| REQ-004 | 模板相关元数据随图替换；保留项目身份/聊天/创作模型 | TC-004 |
| REQ-005 | 弹窗中请求结束更新文案；切换项目关闭待确认操作 | TC-005 |

同轮视觉补充（用户反馈）：使用模板、替换画布、停止并使用模板统一采用主题主色；删除项目和不保存关闭继续使用警示色。复用现有primary/primary-foreground，不新增颜色值。
