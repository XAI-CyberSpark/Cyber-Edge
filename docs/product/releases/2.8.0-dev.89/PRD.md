# 项目与对话自动保存

2026-10-05｜dev.89｜本机实现及所列验收完成，未提交｜依据：用户明确要求Agent项目自动保存，替代必须手动保存的旧约定。

- 首次聊天或画布编辑后自动建档，空白未使用标签不制造项目。
- 对话、公开进度、结果、画布和模型设置自动保存；同项目串行合并，失败自动重试。
- 未同步数据保留浏览器恢复副本；重新打开恢复，旧断开请求标为中断，不重复模型调用。
- 用户最新明确要求：不得新增常驻保存状态行或擅改前端布局，任何新增界面先征得同意。失败沿用现有提示。
- 手动保存/快捷键变为立即保存，无文件名弹窗。冲突时保留内容，告知使用现有保存入口另存副本；关闭已完成标签先保存，失败保留。编排中保持接收结果，可切换项目。
- 不承诺关闭浏览器后编排继续；不引入云账号、云同步或未发送输入草稿保存。
