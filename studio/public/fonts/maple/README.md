# Maple font and palette sources

Maple Mono NF CN Regular v7.900, copyright 2022 The Maple Mono Project Authors.
Font source: https://github.com/subframe7536/maple-font (v7.9)
Web distribution linked by upstream README: https://fonts.zeoseven.com/items/442/
CSS and 191 WOFF2 slices: https://fontsapi.zeoseven.com/442/main/result.css
SIL Open Font License 1.1: see OFL.txt. Font bytes are unmodified. CSS only removes local() lookup for consistent self-hosted rendering. Regular is bundled; browsers synthesize other weights/styles. Unicode ranges load only the required slices.

Palette source: https://github.com/subframe7536/vscode-theme-maple
MIT license: MAPLE-THEME-LICENSE. Main dark surfaces and pastel hues follow Maple; semantic tokens and shade ramps are adapted for application controls and light-mode contrast.

All font files are served locally. No runtime CDN request is required.
